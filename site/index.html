Jung von Matt TECH

Agent Toolkit

Your agents deserve better skills. A reusable skill pack that takes work from raw idea to merged pull request — with a human in the loop at every door that matters.

npx skills add jungvonmatt/agent-toolkit

Works with Claude Code, Copilot, Cursor, Codex, Cline, and more.

One ticket in.
One reviewed pull request out.

Every skill does one job and hands a concrete artifact to the next one: a ticket, a plan, reviewed commits, a review verdict. You can chain the whole flow, or pick the single step you need today.

All skills are namespaced under jvm-skills, so they do not collide with other skill packs.

The flow

From idea to merge

  1. 01

    Ticket

    write-ticket

    Coaches a raw idea into a development-ready ticket.

    Out Jira, GitHub, GitLab, Linear, or Asana issue

  2. 02

    Plan

    start-ticket

    Reads the ticket and the codebase, pressure-tests the requirement.

    Out docs/plans/<ticket>.md

    You answer open questions

  3. 03

    Build

    implement

    Builds, tests, and verifies one vertical slice at a time.

    Out Reviewed commits

    You approve each diff — or run auto

  4. 04

    Review

    pr-review
    scheduled-pr-review

    Severity-ranked findings, on demand or on a schedule.

    Out Merge-ready verdict

Auto-invoked while you build

  • writing-tests behavior-first tests
  • technical-writing comments & docs
  • pr-description when you open a PR
  • voiceover-check real screen reader, on request

Anytime, outside the flow

  • repo-diagnostics churn, bus factor, hotspots
  • design-md reverse-engineer a DESIGN.md
  • jvm-design bootstrap the JvM CI

How to use it

How to use it

  1. Install

    1 · Install the pack

    Add every skill once per machine or per project. Native plugin installs for Claude Code and Codex are below.

    npx skills add jungvonmatt/agent-toolkit
  2. Ticket

    2 · Start from a ticket

    Have an idea? Turn it into a ticket. Already have one? Pass its key or URL and get a plan.

    /jvm-skills:write-ticket  checkout loses the voucher on reload
/jvm-skills:start-ticket  SHOP-1234
  3. Build

    3 · Implement slice by slice

    Run one task and review the working-tree diff before each commit. Trust the plan? Add auto to run it in one approved pass.

    /jvm-skills:implement
/jvm-skills:implement auto
  4. Ship

    4 · Open the PR and review

    Ask for a pull request and its description is written automatically. Then review for merge readiness — or let a scheduled task do a first pass over every open PR.

    /jvm-skills:pr-review

Slash commands shown for Claude Code. In other agents, ask in plain words — "start ticket SHOP-1234" — and the matching skill loads.

The skills

Twelve skills

  • Flow

    write-ticket

    Turns a raw idea, bug report, or feature request into a development-ready ticket and publishes it to your tracker.

  • Flow

    start-ticket

    Fetches a ticket, pulls design specs, explores the codebase, pressure-tests the requirement, and writes a plan.

  • Flow

    implement

    Executes a plan task by task, pausing for a human review of the diff before every commit.

  • Auto

    pr-description

    Writes a concise PR/MR description with a small visual, before/after evidence, and the merge danger.

  • Flow

    pr-review

    Reviews a PR against a target branch with severity-ranked findings, ticket traceability, accessibility, and performance checks.

  • Flow

    scheduled-pr-review

    Runs an unattended first-pass review over all open PRs/MRs from a scheduled task, round after round.

  • Auto

    writing-tests

    Enforces behavior-first, mutation-sensitive tests that query by role or test ID, never by class name.

  • Auto

    technical-writing

    Comments that say why, one Diátaxis mode per page, Simplified Technical English, and a cut test.

  • A11y

    voiceover-check

    Drives the real macOS VoiceOver and compares what it says with what the user must hear.

  • Insight

    repo-diagnostics

    Git-based churn hotspots, bus factor, bug clusters, and velocity — before you read any code.

  • Design

    jvm-design

    Bootstraps the Jung von Matt CI 2026 design system into a project. This page is built with it.

  • Design

    design-md

    Reverse-engineers a design system from Figma, a website, a screenshot, or tokens into a DESIGN.md.

Get started

Install

Skills CLI

Any agent. Install all, browse first, or pick one.

npx skills add jungvonmatt/agent-toolkit 
npx skills add jungvonmatt/agent-toolkit --list
npx skills add jungvonmatt/agent-toolkit --skill pr-review

Claude Code

Native plugin. No Node needed.

claude plugin marketplace add jungvonmatt/agent-toolkit
claude plugin install jvm-skills@jvm-skills

Codex CLI

Native plugin. No Node needed.

codex plugin marketplace add jungvonmatt/agent-toolkit
codex plugin add jvm-skills@jvm-skills

Some skills route to companion skills such as addyosmani/agent-skills and mattpocock/skills. They work without them. See the README.
